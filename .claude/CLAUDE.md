## Что это за репозиторий

`index.html` — тест-диагностика «Денежный компас эксперта» для экспертов и помогающих практиков. Опубликован через GitHub Pages: https://zhukovatatyana001.github.io/denezhny-kompas/

Цель теста — чтобы человек сам квалифицировался и прогрелся до бесплатного 40-минутного личного разбора. На разборе Татьяна предлагает платный формат. Тест должен давать пользу и вау-эффект, а Татьяна должна участвовать как можно меньше до созвона.

Как устроен `index.html` (около 2 МБ, всё в одном файле):

| Блок | Что внутри |
|---|---|
| разметка | первый экран `#landing`, тест `#quiz`, результат `#result` с продающим блоком и формой `#applicationForm` |
| скрипт 1 | логика: `AXES` (7 осей карты), `Q` (вопросы), `baseScores()`, `getPatterns()` (14 сценариев), `showResult()`, `getPersonalBridge()`, отправка формы |
| скрипт 2 | библиотека jsPDF 4.2.1, вставлена целиком |
| скрипт 3 | `PDF_FONT_DATA`: шрифты Noto Sans в base64, около 1,5 МБ |
| скрипт 4 | сборка PDF-карты на устройстве (`downloadCardPdf`) |

Заявка уходит POST-запросом в Google Apps Script (`APPLICATION_ENDPOINT` в коде), оттуда в Google-таблицу. Ответы отправляются только по кнопке «Отправить для личного разбора»; PDF собирается на устройстве и никуда не уходит. Это обещание пользователю, его нужно сохранить.

## Правила работы

1. **Ветка, а не main.** Работай в отдельной ветке. Татьяна смотрит изменения и сама сливает их в main; после слияния GitHub Pages обновляет живой тест.
2. **Репозиторий публичный.** Никаких токенов, ключей и паролей, никаких личных данных клиентов. Токен Telegram-бота хранится в Script Properties в Apps Script, не в коде.
3. **Apps Script живёт не здесь.** Код для него клади в `apps-script/Code.gs` с короткой инструкцией: Татьяна вставит его в редактор Apps Script и нажмёт Deploy. Если меняешь набор полей заявки, меняй их в обоих местах.
4. **Проверяй глазами.** После каждого заметного изменения открывай страницу в Chromium через Playwright на ширине 1280 и 390 px: первый экран, вопрос, результат, форма. Отправку в Apps Script при проверке блокируй. Скриншоты присылай Татьяне.
5. **Не ломай то, что работает.** Тексты 14 сценариев и персональных «мостиков» Татьяне нравятся: дополняй их, а переписывай только после её согласия. Если меняешь вопросы, убедись, что каждый сценарий по-прежнему может сработать.
6. **Сначала показать, потом внедрять.** Дизайн-направление, названия типов и цены сначала показываешь и ждёшь «да».

## Тексты

- Тексты для людей — живая проза от первого лица Татьяны: прямо, по делу, с её опытом. Без «лесенки» (одна фраза — одна строка), без канцелярита, без инфоцыганских обещаний дохода.
- Тест обращается к женщине («я уточняю», «я предлагала»). Так и оставляем, пока Татьяна не скажет иначе.
- Не ставить человеку диагнозов вроде «у вас блок» или «вам мешает страх». Тест показывает факты и расхождения, причину ищут на разборе.

## Дизайн

- Дорого, современно, воздушно, минимализм. Татьяне нужен премиальный уровень, а не «бесплатная Канва из 90-х».
- Запрещено: орнаменты, завитки, рамки, узорные фоны, ар-нуво, викторианский стиль.
- Шрифты храни в репозитории (только с кириллицей) и не подключай Google Fonts ссылкой: для посетителей из ЕС это передача их IP-адресов в Google.
- Системных всплывающих окон (`alert`) быть не должно; подсказки показывай прямо под вопросом.
